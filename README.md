# Year-8-Study

A collection of interactive study resources for a Year 8 student, including a self-contained White Fang Chapter 1 quiz experience.

## Featured project

- White Fang Chapter 1 comprehension quest
- 20 randomized questions every time the page opens
- Shuffled multiple-choice answers for replay value
- XP tracking and bonus-time feedback
- Designed to work as a simple web page and as a GitHub Pages site

## Files

- white-fang-chapter-1.html — the interactive quiz page
- Image assets used in the quiz and story scenes

## Notes

This repository is intended for revision, comprehension practice, and classroom-friendly study activities.
